# Bazaar Boss Pakistan

پاکستانی بازار پر مبنی ایک آف لائن Android گیم۔ اپنی چھوٹی دکان چلائیں، گاہکوں سے بھاؤ تاؤ کریں، ہول سیل منڈی سے سامان خریدیں اور دکان کو بڑا بنائیں۔

## کھیل کی خصوصیات

- مکمل اردو انٹرفیس
- گاہک کی قیمت قبول، رد یا بھاؤ تاؤ کرنے کا انتخاب
- دودھ پتی، بسکٹ، لیموں سوڈا اور مصالحہ چپس کا اسٹاک
- ہول سیل منڈی، دکان کے اپ گریڈ اور انعامی مقاصد
- بدلتے دن: کالج کی چھٹی، بارش اور کرکٹ میچ جیسے واقعات
- موبائل میں پیش رفت خود محفوظ
- مکمل آف لائن؛ کھیلنے کے لیے انٹرنیٹ درکار نہیں

## APK ڈاؤن لوڈ کرنے کا طریقہ

1. GitHub میں **Actions** کھولیں۔
2. تازہ ترین **Build Android APK** رن منتخب کریں۔
3. نیچے **Artifacts** میں `Bazaar-Boss-Pakistan-APK` دبائیں۔
4. ZIP کھول کر `Bazaar-Boss-Pakistan.apk` موبائل میں انسٹال کریں۔

پہلی بار APK نصب کرتے ہوئے Android آپ سے **Install unknown apps** کی اجازت مانگ سکتا ہے۔ صرف اسی APK کے لیے اجازت دیں۔

## مقامی تعمیر

```bash
./gradlew assembleDebug
```

تیار APK یہاں ملے گی:

`app/build/outputs/apk/debug/app-debug.apk`
