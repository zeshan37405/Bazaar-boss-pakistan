# Bazaar Boss Pakistan

پاکستانی بازار پر مبنی ایک آف لائن Android حکمتِ عملی گیم۔ اپنی کریانہ دکان چلائیں، بدلتی منڈی میں صحیح وقت پر سامان خریدیں، گاہکوں سے بھاؤ تاؤ کریں اور روزانہ اخراجات نکال کر کاروبار بڑا بنائیں۔

## کھیل کی خصوصیات

- اردو، ہندی اور انگریزی کا مکمل انٹرفیس
- آٹا، چاول، گھی، کوکنگ آئل، بسکٹ اور ٹافی کا اسٹاک
- ہر دن بدلتی ہول سیل قیمتیں اور سستی/مہنگی قیمت کی نشاندہی
- ہر گاہک کی الگ مقدار، محدود انتظار کا وقت اور مختلف بجٹ
- محفوظ، سمجھدار یا بڑے خطرے والی قیمت پر بھاؤ تاؤ
- روزانہ منافع، فروخت، خوش گاہک یا بہترین خدمت کا نیا چیلنج
- ہر دن دکان کا لازمی خرچ، کامیابی پر نقد انعام اور ناکامی پر ساکھ کا نقصان
- آسان، معیاری اور مشکل درجے
- شادیوں کا موسم، راشن کا رش، مہنگائی اور بجلی کی بندش جیسے واقعات
- ہول سیل منڈی، دکان کے اپ گریڈ اور مستقل کارنامے
- موبائل میں پیش رفت خود محفوظ
- مکمل آف لائن؛ کھیلنے کے لیے انٹرنیٹ درکار نہیں

## APK ڈاؤن لوڈ کرنے کا طریقہ

1. GitHub میں **Actions** کھولیں۔
2. تازہ ترین **Build Android APK** رن منتخب کریں۔
3. نیچے **Artifacts** میں `Bazaar-Boss-Pakistan-APK` دبائیں۔
4. ZIP کھول کر `Bazaar-Boss-Pakistan.apk` موبائل میں انسٹال کریں۔

پہلی بار APK نصب کرتے ہوئے Android آپ سے **Install unknown apps** کی اجازت مانگ سکتا ہے۔ صرف اسی APK کے لیے اجازت دیں۔

## مقامی تعمیر

```bash
./gradlew assembleDebug
```

تیار APK یہاں ملے گی:

`app/build/outputs/apk/debug/app-debug.apk`
